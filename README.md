# Consulta de Legislação Municipal & Retenções de ISS

Este projeto foi desenvolvido para automatizar e otimizar o processo de suporte tributário focado na validação de serviços contratados sujeitos a retenções na fonte.

## 📌 O Problema
Como o ISS (Imposto Sobre Serviços) é de competência municipal, cada localidade possui suas próprias particularidades, alíquotas e regras de retenção. O processo manual de consulta consumia muito tempo, além de gerar a necessidade de manter relatórios complexos ou planilhas paralelas de controle.

## 💡 A Solução
Um sistema web centralizado e favoritado no navegador. Com apenas dois cliques, é possível selecionar o **Município** e o **Código de Serviço** para obter instantaneamente:
* Alíquota vigente e base legal.
* Regras específicas de retenção interna.
* Links diretos para legislações ou decretos municipais relevantes.

> *Nota: A lista de municípios atual contempla as localidades de maior recorrência e contato no dia a dia da operação.*

## 🛠️ Tecnologias Utilizadas
* **Google Apps Script:** Como back-end, processando e buscando os dados em tempo real direto de uma planilha do Google Sheets.
* **HTML5 / CSS3 / JavaScript:** Para a construção de uma interface web moderna, limpa, responsiva e de alta legibilidade (utilizando a fonte Inter e paleta Deep Teal).
